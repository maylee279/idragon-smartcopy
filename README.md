# iDragon Interactive Prototype

Prototype UX/UI giả lập để review giao diện và tương tác. Không kết nối API giao dịch, không gửi lệnh thật và không sử dụng dữ liệu khách hàng.

## Tính năng
- Chuyển Mua/Bán
- Nhập mã, giá và khối lượng; tính tổng tức thời
- Tạo lệnh giả lập, hiển thị Sổ lệnh và tự cuộn đến lệnh mới
- Toast và modal cài đặt cỡ chữ
- Responsive desktop/mobile

## Chạy thử
Mở index.html trong trình duyệt.
